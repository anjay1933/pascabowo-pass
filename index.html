Questions

What is an Agent ID?

Agent ID is an on-chain identity token (ERC-721) on BNB Smart Chain. Pascabowo Pass reads your Agent ID balance on-chain — holding one is the only way to mint.

How much does it cost?

Nothing for the mint itself — the price is 0. You only pay the BNB network gas for the transaction.

Can I mint more than one?

No. The contract allows exactly 1 mint per wallet, enforced on-chain. A second mint from the same wallet will fail.

Is this an investment?

No. This badge has no monetary value promised and is not an investment. It is a free collectible proving you hold an Agent ID.

Is the contract upgradeable or admin-controlled?

No. The contract is fully immutable — there are no admin functions and no owner permissions. Nobody can change the rules, mint extra passes, or pause it after deployment.
